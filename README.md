# Ruixiang Mao · Personal Homepage

Static GitHub Pages homepage for [Moriiikdt](https://github.com/Moriiikdt).

## Deploy

1. Create or open the repository `Moriiikdt.github.io` on GitHub.
2. Copy the contents of this folder into the repository root.
3. Commit and push to the default branch.
4. In **Settings → Pages**, choose **Deploy from a branch**, then select the default branch and `/ (root)`.

The homepage has no build step. `index.html`, `style.css`, and `assets/` can be served directly by GitHub Pages.
